# 发布验证（2026-11-12）

本次验证不占用正在运行的评测GPU，不启动模型下载或7B全量实验。最终CPU测试：**124 passed**（7.66秒），仅有一条环境变量弃用提示。

- 六份科学核心文件（每版config/memory/gpu）与冻结来源逐一核对：配置和视觉事件逻辑保持一致；GPU集成仅调整共享模块导入、将始终空摘要提供器的旧注意力适配器替换成只读Q捕获适配器，保留原生注意力计算。
- CPU测试使用Python 3.12、PyTorch 2.5.1+cu121、Transformers 4.57.3，无checkpoint，无CUDA分配。覆盖两版事件管理、真实小型Qwen的视觉塔与解码、逐层KV释放、因果评分、摘要与文字限额、隔离上下文的异常恢复、新独立包装的连续两段视频和多次调用。
- 独立OVOBench预检解析全部12任务，共3035个问答，逐项检查视频存在。
- 独立StreamingBench预检解析4250个非PO问答，逐项检查视频存在。RTVU2500、OSU1000、其他上下文理解500、SQA250；OSU为纯视觉。
- 运行配置锁定FA2/BF16；CPU单元测试的SDPA不构成FA2性能验证。

历史正确率属于原评测入口。此次没有验证精简入口在完整7B/FA2上的逐问输出和端到端耗时等价性，因此不能将历史准确率写成此包重新测得的成绩。正式复现应固定相同权重、软件版本、硬件、视频采样和问题清单；先做小样本逐问回归，再开展全量。
