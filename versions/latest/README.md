# 最新确认版

使用根目录 `configs/latest.yaml`，通过 `python -m eventkv.evaluate` 运行。

本目录的三个文件是独立的配置、视觉事件管理和GPU KV集成实现；只依赖根目录的必要共享工具，不导入初步改进版。

长期超额时，先判断最老事件：合并树深度≥3，或与直接后继相似度<0.7，则转KV；否则合并全局最低代价相邻对。逐次判断直至满足容量。时间代价改用采样帧位置与当前视觉向量数权重。摘要生成隔离无关历史KV；文字重写真正只用文字。详见 `docs/VERSIONS.md`。

这个最新组合尚无完整全量结果。请使用显式YAML，配置类保留的历史消融默认值不代表本版本的推荐运行设置。
